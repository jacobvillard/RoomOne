[Gobsmacked!](https://roomone.dpdns.org/) is a multiplayer party game starring physics-based goblins thrown into a variety of chaotically hilarious and wacky scenarios. Players join a central lobby and launch into different mini-games, each one testing their skill, timing and ability to survive all the absurdity that will follow - all using a unified goblin character mesh full of charm, charisma and glory.

## 📄 Documentation

See below for quickstart installation.
<details open>
<summary>Install</summary>


Download the latest [Unreal Engine 5.5.4](https://www.unrealengine.com/en-US/download) and install it using the `Epic Games Launcher`.

✅ 1. Download the Bootstrapper
```bash
# You can replace vs_community.exe with:
# vs_professional.exe for Professional Edition
# vs_enterprise.exe for Enterprise Edition
curl -LO 'https://aka.ms/vs/17/release/vs_community.exe'
```

✅ 2. Run the Installer with Command-Line Arguments
```bash
# This command installs the Visual Studio Community Edition with the Native Game workload.
vs_community.exe --quiet --wait --norestart --nocache ^
--add Microsoft.VisualStudio.Workload.NativeGame
```

✅ 3. Install .NET SDK
```bash
# Optionally, you can update the .NET SDK to the latest version.
dotnet-sdk-6.0.x-win-x64.exe /quiet /install
```
</details>

## 🎨 Features

- 🧌 **Goblin Mayhem** – Play as chaotic, customizable goblins in wacky environments.
- 🤸 **Ragdoll Physics** – Dynamic and hilarious physics-driven interactions.
- 🎮 **Multiplayer Madness** – Join friends or strangers in competitive and cooperative mayhem.
- 🎲 **Variant Gameplay Scenarios** – Every round throws you into a different mini-game challenge.
- 🧠 **Lobby System** – Seamlessly match, chat, and launch games from a shared social hub.
